Reshma KS – Personal Portfolio Website
About the Project
This is a responsive personal portfolio website created to introduce Reshma KS, a B.Tech Computer Science and Engineering student at Jawaharlal College of Engineering and Technology (JCET), Lakkidi.
The website presents personal information, technical skills, education, projects, learning journey, current learning interests, and contact details in one place.
Features
Responsive design for desktop and mobile devices
Home section with an introduction
About Me section with personal and academic details
Technical Skills section
Education section
Projects showcase
Learning Journey timeline
Currently Learning section
Contact section with email, LinkedIn, GitHub, and phone links
Dark mode and light mode toggle
Mobile navigation menu
Typing text animation
Interactive skill cards
Scroll reveal animations
Back-to-top button
Automatic copyright year
Technologies Used
HTML5 – website structure
CSS3 – styling, layout, animations, and responsive design
JavaScript – interactive features and dynamic behaviour
Project Structure
portfolio-website/
├── index.html
└── README.md
The CSS and JavaScript are included inside the index.html file.
How to Run the Project
Download or clone this repository.
Open the project folder.
Open index.html in a web browser.
Explore the different sections of the portfolio.
Customization
You can update the personal information, skills, education, project descriptions, email address, phone number, and social profile links in index.html.
Future Enhancements
Add more academic and personal projects.
Connect a working contact form.
Add a downloadable resume.
Include links to completed projects.
